# The secondary-structure dependence of indel cost is a property of the residue, not of the indel

Analysis code, pre-registrations and results for the manuscript of the same name.

Single-residue insertions and deletions are usually summarised by secondary-structure class:
helices tolerate indels poorly, strands worse still, loops best. Using the mega-scale folding
stability measurements of Tsuboyama et al. (2023), this work compares insertions and deletions
**at the same position in the same protein** and finds that the structure dependence tracks the
identity of the residue involved, not the edit itself.

| path | contents |

| `PREREG_*.md` | pre-registrations, written before each test was run |

## Pre-registrations, including the ones that failed

Each test was written down before it was run, with its pass and fail conditions fixed in advance.
**The failed ones are kept here on purpose.** Three claims that looked strong were withdrawn on
their own controls and are reported as negatives in the manuscript:

- a within-protein advantage of strands over helices, which did not replicate in 57 designed
  miniproteins;
- "the insertion/deletion asymmetry vanishes at intolerant positions", which turned out to be a
  regression-to-the-mean artefact of binning a difference on one of its own measurements;
- a gain from modelling the residue-by-structure interaction, which improves prediction in only
  51.7% of domains and is worse once geometry is included.

`PREREG_abundance_proxy.md` and `RESULTS_abundance_proxy.md` are a separate, self-contained
question: whether a general abundance assay can substitute for a protein-specific function assay.
It cannot, and the write-up records two datasets that were retrieved and then rejected, with the
reasons.

## Reproducing

Scripts take their inputs as command-line arguments and write JSON to `results/`. Requires
Python 3 with `pandas`, `numpy`, `scipy` and `statsmodels`; `matplotlib` for the figures.

```
python analysis/41_verify.py <lib3.csv> <af_models_dir> results/ results/verify.json
python paper/update_numbers.py results/ paper/ paper/numbers.tex
cd paper && latexmk -pdf main.tex
```

`analysis/41_verify.py` re-derives the manuscript's headline numbers from the raw library alone,
deliberately without reading any earlier intermediate file.

Every number quoted in the manuscript is a LaTeX macro generated by `paper/update_numbers.py`
from the analysis outputs; `numbers.tex` is never edited by hand. A macro with no source is
emitted as a red **MISSING**, so a paper with a silently absent value cannot be compiled.

## Data

Not redistributed here. Download from the original sources:

- **Tsuboyama et al. 2023**, mega-scale folding stability, Zenodo deposit `7992926`, library 3.
  The AlphaFold models used for secondary structure are part of the same deposit.
- **MaveDB** score sets for the abundance-proxy analysis, fetched by URN through the public API
  (`https://api.mavedb.org/api/v1/score-sets/<urn>/scores`). The URNs are listed at the top of
  `analysis/46_abundance_proxy.py` and `analysis/47_indel_proxy.py`.

## Secondary structure

Assigned with the hydrogen-bond rules of Kabsch & Sander (1983), implemented from scratch in
`analysis/17_dssp.py` on the deposited AlphaFold models. It is validated two ways in
`analysis/18_ss_check.py` and `analysis/23_ss_crosscheck.py`: against backbone geometry the
algorithm never uses, and against an independently produced assignment for the same domains.

An earlier version of this project used a cruder Ramachandran-box assignment that labelled about
89% of residues as helix or strand. Every affected number was recomputed. One previously failing
pre-registered mark passes under the corrected assignment; both values are reported together in
the write-ups rather than only the one that passes.
